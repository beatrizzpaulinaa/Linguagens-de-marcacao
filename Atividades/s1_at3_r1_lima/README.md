## 📌 Sobre o Projeto

Este projeto consiste na criação de uma página HTML simples com o objetivo de apresentar informações pessoais, hobbies e objetivos para o futuro profissional.

A página foi desenvolvida utilizando **HTML puro**, sem a utilização de CSS ou JavaScript, com foco na aplicação de **boas práticas de HTML semântico**, organização do código e acessibilidade.

## 🎯 Objetivo

O objetivo principal é praticar a utilização correta dos elementos semânticos do HTML, compreendendo como eles ajudam a estruturar uma página de forma lógica, clara e acessível.

Além disso, o projeto busca demonstrar a importância de utilizar elementos HTML de acordo com sua finalidade, facilitando a interpretação do conteúdo por navegadores e tecnologias assistivas, como leitores de tela.

## 🛠️ Tecnologias Utilizadas

* HTML5
* Visual Studio Code
* Git
* GitHub

## 📄 Estrutura da Página

A página contém as seguintes partes:

### Cabeçalho

Utiliza a tag `<header>` para apresentar o título e uma breve introdução da página.

### Sobre Mim

Utiliza `<section>` e `<h2>` para apresentar informações sobre a estudante, sua formação e seus interesses.

### Hobbies

Apresenta alguns hobbies e atividades realizadas no tempo livre.

### Futuro Profissional

Descreve expectativas, objetivos e interesses relacionados ao futuro profissional.

### Rodapé

Utiliza a tag `<footer>` para apresentar o copyright da página.

## ♿ Acessibilidade e HTML Semântico

Um dos principais objetivos do projeto é utilizar uma estrutura HTML semanticamente correta.

Foram utilizados elementos como:

* `<header>` — representa o cabeçalho da página;
* `<main>` — identifica o conteúdo principal;
* `<section>` — organiza o conteúdo em diferentes assuntos;
* `<h1>` e `<h2>` — estabelecem uma hierarquia de títulos;
* `<footer>` — representa o rodapé da página.

Essa organização facilita a compreensão do conteúdo por leitores de tela e outras tecnologias assistivas. A utilização do atributo `lang="pt-BR"` também informa ao navegador e aos leitores de tela que o conteúdo está em português do Brasil.


## 💡 Boas Práticas Aplicadas
